DEPLOYMENT INFORMATION
================================================================================

Prerequisites:
  • Python 3.7+
  • Flask 2.0+
  • PyMySQL 1.0+
  • MySQL 5.7+ (tested on 8.x)
  • Linux/WSL environment

Installation Steps:
  1. Backup database: mysqldump -u schooluser -p schoolmngt > backup.sql
  2. Run migration: mysql -u schooluser -p schoolmngt < school_management_migration_v1.sql
  3. Update app.py: Already done (includes imports and routes)
  4. Restart Flask: pkill python3 app.py && python3 app.py
  5. Verify: curl http://localhost:5000/login

Verification:
  • Run test suite: python3 test_class_system.py
  • Expected: 7/7 tests passed
  • Time: < 5 minutes

Rollback (if needed):
  1. Stop Flask app: pkill -f "python3 app.py"
  2. Restore database: mysql -u schooluser -p schoolmngt < backup.sql
  3. Restart app: python3 app.py
  4. Time to rollback: < 10 minutes
