ROUTES EXPOSED BY UI (All Admin-Only)
================================================================================

GET  /admin/manage_classes
     → Renders: class_management_dashboard.html
     → Shows: Dashboard with statistics and 6 feature cards
     → Access: Admin users only

GET|POST  /admin/classes/create
          → Renders: create_class.html
          → Action: Create new class
          → Access: Admin users only

GET|POST  /admin/classes/promote
          → Renders: promote_students.html
          → Action: Promote students atomically
          → Access: Admin users only

GET|POST  /admin/class/<id>/subjects
          → Renders: manage_class_subjects.html
          → Action: Allocate subjects to class
          → Access: Admin users only

GET|POST  /admin/teacher/allocate
          → Renders: allocate_teacher.html
          → Action: Assign teacher to class-subject
          → Access: Admin users only

GET|POST  /admin/student/<id>/subjects
          → Renders: enroll_student_subjects.html
          → Action: Enroll student in subjects
          → Access: Admin users only

GET  /admin/class/<id>/get-subjects
     → Returns: JSON list of subjects for class
     → Purpose: Used by AJAX form population
     → Access: Admin users only

GET  /admin/get-classes-by-year
     → Returns: JSON list of classes for academic year
     → Purpose: Used by AJAX form population
     → Access: Admin users only
