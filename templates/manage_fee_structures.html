Structure Governance & Rules

  • One Active Structure per Scope: Each Academic Year + Class + Billing Group maintains exactly one active fee structure definition containing all 3 terms.
  • Versioning & Immutability: Historical versions are preserved for audit and reporting. Modify active structures via the Version Control workflow (Clone → Draft → Approve → Activate).
  • Discounts & Optional Services: Staff discounts, scholarships, transport, and clubs are configured separately through Discount Profiles and Optional Services rather than multiplying fee structures.
