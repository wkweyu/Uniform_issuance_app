�� SECURITY LAYERS

  Layer 1: Authentication
  ├─ Checks: Is user logged in? (session['userNo'] exists)
  ├─ Action: If no → Redirect to /login with URL preservation
  └─ Status: Covers all sensitive routes ✓

  Layer 2: Authorization  
  ├─ Checks: Does user have required role? (session['is_admin'] == True)
  ├─ Action: If no → Flash error and redirect to dashboard
  └─ Status: Covers admin-only functions (/manage_prices, /admit) ✓

  Layer 3: CSRF Protection
  ├─ Checks: Is form submission valid? (CSRF token matches session)
  ├─ Action: If no → Return 400 Bad Request
  └─ Status: Covers all form submissions ✓

❓ COMMON QUESTIONS

  Q: Is the app ready for production use?
  A: Technically yes. Recommended: Change secret_key and enable HTTPS first.

  Q: How do I make a user an admin?
  A: UPDATE users SET TA = 1 WHERE userNo = 'user_id';

  Q: What happens if someone removes the CSRF token from HTML?
  A: Form submission will be rejected with a 400 error.

  Q: Can I disable CSRF protection for specific routes?
  A: Yes, use @csrf.exempt decorator (already applied to 4 JSON endpoints).

  Q: How long does session last?
  A: Default: Browser session. Customizable via PERMANENT_SESSION_LIFETIME.
